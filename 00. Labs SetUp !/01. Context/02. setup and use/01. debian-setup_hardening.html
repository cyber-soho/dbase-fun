Guide 2 · Debian 13 with LXQt: install, set up, harden

You install Debian 13 with the LXQt desktop into the virtual machine, bring it up to date, add the drivers that make the window resizable and the clipboard shared, harden it with one script, and record the result as a snapshot.

Start

Why Debian 13 with LXQt

The choice of the guest system, and the evidence for it
Why this step. The guest system should take as little memory as possible from a student laptop, show a full graphical desktop, and run every database tool of the course from its publisher's own packages.

The course needs a system that satisfies four conditions at once: a graphical desktop for DBeaver and the browser; the smallest memory footprint that still gives a complete desktop; official packages of PostgreSQL, DBeaver, Valkey, Spark and JupyterLab; and the same system available at AWS (Amazon Web Services), so that Guide 4 can rebuild the machine there with the same script. Debian 13 (code name trixie) with the LXQt desktop is the lightest system that meets all four.

CandidateWhat speaks for itWhat speaks against itDecision
Debian 13 with LXQt 2.1LXQt is the lightest complete desktop (figures below). Free software only by default. The PostgreSQL project, DBeaver and the other publishers ship packages for it; Valkey is part of Debian itself. Official Debian images exist on AWS. Security updates until 2028, long-term support until 2030.PostgreSQL 18 comes from the PostgreSQL project's own repository, because Debian 13 itself carries version 17. The installer of Guide 3 adds that repository.Chosen
Lubuntu 26.04 LTS (Long-Term Support), which is Ubuntu with LXQtThe same desktop; PostgreSQL 18 is in the system's own repository; very widely documented.Ubuntu's base runs additional background services, among them the snap service, and delivers Firefox through it. In the test cited below LXQt on Ubuntu 26.04 used 745 MiB (mebibyte, 1,048,576 bytes) when idle.Good second choice; the scripts of these guides also run on it
Xubuntu, Ubuntu, KubuntuFamiliar to many students.Heavier in the same test, measured when idle: the desktop Xfce took 888 MiB, the desktop GNOME 894 MiB and the desktop KDE Plasma 1,209 MiB.Not chosen
antiX, Alpine Linux with a desktopUse even less memory.antiX has no systemd and Alpine uses a different C library, so the publishers' packages and instructions for the course tools do not apply directly.Not chosen

The figures come from a test published on 12 October 2026 that installed seven desktops on the same Ubuntu 26.04.1 base in a virtual machine with 2 processors and 4 GB (gigabyte) of memory and measured the memory in use five minutes after login: Desktop Environment RAM Usage, computingforgeeks.com. The same system without any desktop used 427 MiB, so LXQt itself cost 318 MiB, the least of the seven. No comparable published measurement exists for Debian 13 with LXQt; measure your own machine with the command free -m after step 3 and compare.

Good to knowDebian decides what may enter its main archive with the Debian Free Software Guidelines (DFSG). The Open Source Definition of the Open Source Initiative, against which the course checks the licence of every database, was derived from those guidelines.
Your choice of toolsEvery tool in this guide is open-source software, and every one is a proposal. You may replace any of them with another suitable tool that is available to you, provided that you can justify the choice. Research your tools thoroughly: read the licence, the documentation and the date of the last release. Be creative; you may even build a tool of your own. The scripts of Guides 2 and 3 accept Debian 13, Ubuntu 24.04, Ubuntu 26.04 and Lubuntu.
Step 1

Start the installer from the live desktop

Actions 1 and 2 · 3 minutes
Why this step. The image starts a complete Debian desktop from the ISO (International Organization for Standardization; here: a disc image file) file without changing anything. The installation begins only when you ask for it.

The VM (Virtual Machine) window shows the menu of the image (end of Guide 1). Click inside the window and press Enter on Live system (amd64). Wait about a minute for the desktop.

Double-click the icon Install Debian on the desktop. The installer window opens; it is a program called Calamares.

✔ Done when: the installer shows its first page, Welcome.
Step 2

Install Debian in seven screens

Actions 3 to 6 · 15 to 25 minutes, most of it waiting
Why this step. The installer writes Debian onto the virtual disk of the VM (Virtual Machine) and creates your account. It asks only what it cannot decide for you.
ScreenWhat to enterWhy
WelcomeLanguage: American EnglishThe course material and all error messages you will search for are in English.
LocationYour region and zone, for example Europe / MadridSets the clock of the guest.
KeyboardThe layout printed on your keys; test the keys @, {, } and | in the test boxSQL (Structured Query Language) and the terminal use these characters constantly.
PartitionsErase disk; leave Swap (no Hibernate)The disk meant here is the 40 GB (gigabyte) virtual disk of the VM. The disk of your own computer cannot be reached from inside the VM.
UsersYour name; a short login name in lower case, for example student; computer name it505-lab; a password of at least 10 characters. Leave Log in automatically unticked.The login name appears in every path and prompt. The password protects the administrator rights of your account.

FinishLeave Restart Now ticked; choose DoneThe guest restarts from its own disk.

Go through the screens Welcome, Location and Keyboard with the values of the table.

On Partitions choose Erase disk. On Users fill in the five fields and leave automatic login unticked. Write the password down now.

On Summary choose Install, confirm with Install Now, and wait for the progress bar (5 to 15 minutes).

On Finish choose Done. When the black screen asks you to remove the installation medium, press Enter. The login screen of your new system appears.

Good to knowIf your installer shows a box Use the same password for the administrator account, leave it ticked. Your account then administers the machine through the command sudo, and the separate account root has no password of its own.
✔ Done when: the login screen shows your name.
Step 3

First login and first update

Actions 7 and 8 · 5 to 10 minutes
Why this step. An installation image is always older than today. The first update installs the corrections published since the image was made.

Log in. Open a terminal: Menu > System Tools > QTerminal. Keep this path in mind; you will need a terminal in almost every step.

Type the update command, press Enter, type your password and press Enter again. When the prompt returns, restart the guest with the second command.

Terminal
# Read the current list of packages, then install every available update; -y answers the question with yes.
sudo apt update && sudo apt full-upgrade -y
Terminal
# Restart the guest, so that the updated system is the one that runs.
sudo reboot
Part of the commandMeaning
sudoRun the following command with administrator rights. It asks for your password. While you type it, the terminal shows nothing.
apt updateRead the current lists of packages from the Debian servers. APT (Advanced Package Tool) is the package manager of Debian.
&&Run the next command only if the previous one succeeded.
apt full-upgrade -yInstall every available update; -y answers the confirmation question with yes.
✔ Done when: after the restart, sudo apt update ends with All packages are up to date.
Step 4

Guest Additions: a resizable screen and a shared clipboard

Actions 9 to 12 · 10 minutes
Why this step. The Guest Additions are drivers for the simulated hardware. With them the desktop follows the size of the VM (Virtual Machine) window, and text copied on the host can be pasted in the guest. Without the shared clipboard every command of the next guides would have to be typed by hand.

Install the tools with which the drivers are built for your kernel.

Terminal
# Install the compiler and the kernel headers that the drivers need in order to be built.
sudo apt install -y build-essential dkms linux-headers-amd64

In the menu bar of the VM window choose Devices > Insert Guest Additions CD (Compact Disc) Image. Nothing visible happens: a virtual disc is now in the virtual drive. Then mount it and run its installer.

Terminal
# Make the disc readable under /mnt, then run the installer that is on it.
sudo mount /dev/sr0 /mnt && sudo sh /mnt/VBoxLinuxAdditions.run

Restart the guest.

Terminal
# Restart, so that the new drivers are loaded.
sudo reboot

After logging in again choose Devices > Shared Clipboard > Bidirectional. Resize the VM window: the desktop follows. Test the clipboard: copy this line on the host and paste it into QTerminal with Ctrl+Shift+V.

Terminal
# Print one line with today's date: it proves that text copied on the host arrives in the guest.
echo "The clipboard works on $(date)"
Good to knowIn QTerminal, copy is Ctrl+Shift+C and paste is Ctrl+Shift+V. Ctrl+C has a different meaning in a terminal: it stops the running command. On a Mac with Apple Silicon the headers package is called linux-headers-arm64.
✔ Done when: the desktop fills the window after resizing, and a text copied on the host can be pasted in the guest.
Step 5

Harden the machine

Actions 13 to 15 · 5 minutes
Why this step. Hardening reduces what can go wrong on a machine: fewer programs that listen on the network, updates that install themselves, and settings that refuse unsafe input. A database server deserves this care even in a lab.

nine settings and ten checks; every command in it is commented · 16 KB (kilobyte)

Open this guide in Firefox inside the VM (Virtual Machine) and use the button above; the script is saved to the folder Downloads. If the guide is only on the host, open the script there, copy its whole text, and in the guest paste it into a new file with the editor FeatherPad (Menu > Accessories).

Run the script. It applies the settings, then checks them.

Terminal
# Go to the folder Downloads and run the hardening script with administrator rights.
cd ~/Downloads && sudo bash it505_harden.sh

Read the ten result lines. Each should begin with [PASS]. A line with [WARN] names what is still open. Repeat the check whenever you like:

Terminal
# Run only the ten checks; nothing is changed.
sudo it505-harden --check
SettingWhat it doesThe same by hand
1 UpdatesInstalls every pending update.sudo apt update && sudo apt full-upgrade
2 Automatic security updatesLets the package unattended-upgrades install security corrections every day without you.sudo apt install unattended-upgrades, then two lines in /etc/apt/apt.conf.d/20auto-upgrades
3 FirewallSwitches on ufw: connections from outside are refused, connections from the guest to the outside are allowed.sudo ufw default deny incoming, sudo ufw default allow outgoing, sudo ufw enable
4 Unneeded servicesStops the printing, device-discovery, Bluetooth and modem services, which a lab machine does not use.sudo systemctl disable --now cups avahi-daemon bluetooth ModemManager
5 Remote loginSwitches off an SSH (Secure Shell) server if one is installed. Nobody logs in to this machine over the network.sudo systemctl disable --now ssh
6 The account rootLocks the password of root. Administration goes through sudo and your own password.sudo passwd -l root
7 Kernel network settingsRefuses redirected and source-routed packets and hides kernel addresses from ordinary accounts.A file in /etc/sysctl.d/, loaded with sudo sysctl --system
8 Private home folder, no automatic loginCloses your home folder to other accounts and removes automatic login from the login manager.chmod 750 ~
9 RecordNotes the date, and installs the check as the command it505-harden.

Three protections are already in place before the script runs, and the check confirms them. AppArmor, which confines programs to the files they need, is switched on in Debian by default. The network adapter of the VM uses NAT (Network Address Translation): the guest can reach the internet, but no other computer can open a connection to the guest. The database servers of Guide 3 listen only on the address of the machine itself, localhost.

Good to knowThe script does not encrypt the virtual disk, and it does not replace sensible habits: lock the screen when you leave (Menu > Leave > Lock Screen), keep passwords out of files and notebooks, and use only fictional or open data in the labs.
✔ Done when: the last line reads Result: 10 of 10 checks passed.
Step 6

Take a snapshot: your restore point

Actions 16 and 17 · 2 minutes
Why this step. A snapshot records the complete state of the VM (Virtual Machine). If a later step fails, restoring the snapshot brings the machine back to this moment in seconds, which is faster than repairing it.

Shut the guest down properly: Menu > Leave > Shutdown. Closing the VM window with Power off the machine is like pulling the plug and can damage files.

In VirtualBox Manager select IT505-Lab, open the tab Snapshots, choose Take, and name the snapshot 01-clean-hardened.

TipSnapshots take disk space on the host, because every change after a snapshot is stored separately. Keep the two that these guides name, and delete experimental ones when they are no longer needed.
✔ Done when: the snapshot 01-clean-hardened is listed above Current State.

Help

If something goes wrong

Seven frequent situations, with their cause and remedy
What you seeCause and remedy
After the installation the installer starts againThe ISO (International Organization for Standardization; here: a disc image file) image is still in the virtual drive. Devices > Optical Drives > Remove Disk From Virtual Drive, then Machine > Reset.
The desktop does not follow the window sizeThe Guest Additions are missing or were built before a kernel update. Repeat step 4. Also check View > Auto-resize Guest Display.
VBoxLinuxAdditions.run reports that kernel headers are missingThe first command of step 4 did not finish. Run it again, then run the installer again.
student is not in the sudoers fileThe account has no administrator rights (this happens when a password was set for root during installation). Type su -, give the password of root, then usermod -aG sudo student, then reboot.
Some characters do not match your keysWrong keyboard layout. sudo dpkg-reconfigure keyboard-configuration, then restart.
Could not get lock /var/lib/dpkg/lockThe automatic update is running at this moment. Wait two minutes and repeat the command.
You forgot your passwordRestore the snapshot if you remember the password of that moment; otherwise delete the VM (Virtual Machine) and repeat Guides 1 and 2. A forgotten password cannot be read from the system.
