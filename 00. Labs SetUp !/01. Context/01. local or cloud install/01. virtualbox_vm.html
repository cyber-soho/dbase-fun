Guide 1 · VirtualBox and the virtual machine

You install VirtualBox 7.2.22 on your own computer and create the virtual machine IT505-Lab, the simulated computer in which every lab of the course will run. Your own system is not changed: the lab lives in one folder that you can copy, restore or delete.

Start

What you are building, and what you need

Five terms · four requirements · two paths
Why this step. A virtual machine lets the whole class work on identical systems, whatever computer each person owns. It also protects your own system: a mistake made inside the virtual machine stays inside it.

Five terms are used in all four guides. The host is your physical computer. The hypervisor is the program that creates and runs simulated computers; here it is VirtualBox. A virtual machine (VM) is one such simulated computer, with simulated processors, memory, disk and network card. The guest is the operating system installed inside the VM; here it is Debian 13. An ISO (International Organization for Standardization; here: a disc image file) image is the complete content of an installation disc stored as one file.

RequirementMinimumWhy
Processor64-bit, with hardware virtualization switched on. Intel calls this function VT-x (Virtualization Technology for x86 processors); AMD (Advanced Micro Devices, a maker of processors) calls it AMD-V (AMD Virtualization).The hypervisor runs the guest directly on the processor. Almost every computer sold since 2012 has this; some have it switched off in the firmware (see Help).
Memory8 GB (gigabyte) of RAM (Random-Access Memory) in the hostThe VM receives 4 GB while it runs. With less than 8 GB in the host, give the VM 2 GB and use the cloud twin of Guide 4 for the Spark exercise.
Free disk space25 GBThe ISO image takes 3.7 GB; the disk file of the VM grows to about 15 GB once everything is installed.
Internetabout 4.2 GB of downloadsVirtualBox takes 170 MB (megabyte) and the Debian image 3.7 GB; later the tools take about 1.5 GB inside the VM.
AttentionMac with Apple Silicon (M1 to M5). VirtualBox 7.2 runs only Arm guests on an Arm host: an x86_64 VM does not start there, and Oracle's release notes name only Oracle Linux and Windows 11 as supported Arm guests. The dependable path for these Macs is the cloud twin of Guide 4. To try a local machine anyway, download the package macOS / Apple Silicon hosts, and instead of the live image take the file whose name ends in arm64-netinst.iso from the Debian download folders. Its installer is a different program from the one shown in Guide 2: choose LXQt on the screen Software selection, and leave the password of root empty so that your own account receives administrator rights. Guides 2 (from step 3) and 3 then apply unchanged. This path was not rehearsed for this guide.
For the professorTwo paths lead to the same machine. Path A: every student follows Guides 1, 2 and 3 (about three hours in total, most of it waiting). Path B: you build the machine once, export it as one file (Guide 3, last step), and students only install VirtualBox (steps 1 and 2 here) and import your file (step 6). Path B fits the install party of Class 1; Path A is a good home sprint.
Your choice of toolsEvery tool in this guide is open-source software, and every one is a proposal. You may replace any of them with another suitable tool that is available to you, provided that you can justify the choice. Research your tools thoroughly: read the licence, the documentation and the date of the last release. Be creative; you may even build a tool of your own.
Step 1

Download VirtualBox and check the file

Actions 1 to 3 · 5 minutes plus the download
Why this step. Software is downloaded from its publisher, never from a download portal. The fingerprint check proves that the file on your disk is, bit for bit, the file the publisher released.

Open the download page of VirtualBox: www.virtualbox.org/wiki/Downloads. The same packages are listed on Oracle's download page, which names version 7.2.22 as the latest release.

Download the package for your host. Windows: VirtualBox-7.2.22-175245-Win.exe. Mac with Intel processor: VirtualBox-7.2.22-175245-OSX.dmg. Mac with Apple Silicon: VirtualBox-7.2.22-175245-macOSArm64.dmg. Linux: the package named after your distribution.

Open the link SHA256 checksums on the download page, compute the SHA-256 (Secure Hash Algorithm, 256-bit) fingerprint of your file with the command for your system, and compare the two. They must be identical in every character; upper and lower case do not matter.

Windows: PowerShell
# Compute the fingerprint of the downloaded installer, to compare it with the publisher's list.
Get-FileHash $HOME\Downloads\VirtualBox-7.2.22-175245-Win.exe -Algorithm SHA256
macOS: Terminal
# The same check on a Mac; the star stands for the rest of the file name.
shasum -a 256 ~/Downloads/VirtualBox-7.2.22-175245-*.dmg
Linux: terminal
# The same check on Linux.
sha256sum ~/Downloads/virtualbox-7.2_*.deb
Good to knowYou do not need the VirtualBox Extension Pack. It is a separate download under a different licence, free of charge only for personal and educational use, and nothing in this course uses it. The base package is free software under the GPL (GNU General Public License) version 3, a licence of the GNU (GNU's Not Unix, the name of a free-software project) project.
✔ Done when: the fingerprint of your file equals the one in the publisher's list.
Step 2

Install VirtualBox

Actions 4 and 5 · 5 minutes
Why this step. The installer adds the hypervisor and its network drivers to the host. Every default setting is suitable.

Windows. Double-click the downloaded file and follow the six screens of the animation: Next, Next, Yes, Yes, Install, Finish. If the installer asks for the Microsoft Visual C++ Redistributable, install it from Microsoft first, then start the VirtualBox installer again.

HostHow to install
macOSOpen the .dmg file, double-click VirtualBox.pkg, choose Continue and Install, and type your password. Then start VirtualBox from the folder Applications.
Debian or UbuntuIn a terminal, in the folder of the download: sudo apt install ./virtualbox-7.2_*.deb. To pass USB (Universal Serial Bus) devices to a guest later, add yourself to the group vboxusers with sudo usermod -aG vboxusers $USER and log in again; the course does not need this.
Other LinuxUse the package for your distribution from the same download page, or the generic installer VirtualBox-7.2.22-175245-Linux_amd64.run.

Start VirtualBox. The window is called Oracle VirtualBox Manager. On the welcome page keep the experience level Basic: it shows the settings a first-time user needs and hides the rest.

Good to knowVirtualBox 7.2 arranges its window differently from older versions. The global tools (Home, Machines, Extensions, Media, Network, Cloud, Activities) form a vertical bar at the left edge; the tools of the selected VM (Virtual Machine) are tabs above the right-hand panel: Details, Snapshots, Logs, Activity and File Manager.
✔ Done when: VirtualBox Manager is open and shows its welcome page.
Step 3

Download the Debian 13 image and check it

Actions 6 and 7 · 5 minutes plus a 3.7 GB download
Why this step. The guest system comes as one ISO (International Organization for Standardization; here: a disc image file) image. The LXQt edition is a live image: it starts a complete desktop first and contains a graphical installer, which Guide 2 uses.

Open the folder of the Debian live images for 64-bit Intel and AMD (Advanced Micro Devices, a maker of processors) processors: cdimage.debian.org/debian-cd/current-live/amd64/iso-hybrid/. Download the file whose name ends in amd64-lxqt.iso; its size is 3.7 GB (gigabyte). Start this download first if your connection is slow; you can continue with step 4 only when it is complete.

In the same folder open SHA256SUMS, compute the SHA-256 (Secure Hash Algorithm, 256-bit) fingerprint of the ISO file as in step 1, and compare it with the line of that list that carries the name of your file.

Windows: PowerShell
# Compute the fingerprint of the Debian image; the star matches 13.7.0 as well as 13.8.0.
Get-FileHash $HOME\Downloads\debian-live-13.*-amd64-lxqt.iso -Algorithm SHA256
macOS: Terminal
# The same check on a Mac.
shasum -a 256 ~/Downloads/debian-live-13.*-amd64-lxqt.iso
Linux: terminal
# The same check on Linux.
sha256sum ~/Downloads/debian-live-13.*-amd64-lxqt.iso
Good to knowDebian 13.8 was published on Saturday 21 November 2026, the day this guide was written, and the download folder was changing from the 13.7.0 files to the 13.8.0 files. Take the lxqt.iso that the folder offers: the first update inside the guest (Guide 2, step 3) brings either one to the same state. Why Debian 13 with LXQt was chosen is explained at the start of Guide 2.
✔ Done when: the ISO file is on your disk and its fingerprint matches.
Step 4

Create the virtual machine

Actions 8 to 10 · 3 minutes
Why this step. This step describes the simulated computer: its name, its memory, its processors and its disk. Nothing is installed yet.

In VirtualBox Manager choose Home, then New. In the first section type IT505-Lab into the field VM (Virtual Machine) Name and choose your Debian file in the field ISO (International Organization for Standardization; here: a disc image file) Image. VirtualBox then sets OS to Linux, OS Distribution to Debian and OS Version to Debian 13 Trixie (64-bit); if it does not, choose these three values yourself.

Make sure that the box Proceed with Unattended Installation is not ticked. An unattended installation answers the installer's questions for you; it does not work with a live image, and Guide 2 installs by hand.

Open the section Specify virtual hardware and set the values of the table; open Specify virtual hard disk and set the disk size. Then choose Finish.

SettingValueExplanation
Base Memory4096 MB (megabyte); only 2048 MB if the host has less than 8 GB (gigabyte) of memoryMemory lent to the guest while it runs. Stay within the green part of the slider: the host needs the rest.
Number of CPUs (Central Processing Unit)2Two simulated processors keep the desktop responsive. Never assign more than half of the host's processors.
Use EFI (Extensible Firmware Interface)not tickedThe guest then starts through the classic BIOS (Basic Input/Output System) method, which needs no further settings.
Disk Size40 GBThe upper limit of the disk file. The file starts small and grows only as the guest stores data.
✔ Done when: IT505-Lab appears in the list at the left, with the state Powered Off.
Step 5

One setting, then the first start

Actions 11 and 12 · 3 minutes
Why this step. More video memory avoids display faults when the guest fills the whole screen. The first start proves that the hypervisor, the VM (Virtual Machine) and the image work together.

Select IT505-Lab, choose Settings, open Display, and move Video Memory to 128 MB (megabyte). Leave Enable 3D Acceleration unticked. Confirm with OK.

Choose Start. A window opens and shows the menu of the Debian image. Leave it there: Guide 2 continues from this menu. To stop for today instead, close the window and choose Power off the machine.

TipWhen you click inside the window of the VM, the guest may capture the mouse pointer. The Host key gives it back: by default the right Ctrl key on Windows and Linux, and the left Command key on macOS. The current Host key is shown at the bottom right of the VM window.
✔ Done when: the VM window shows the Debian menu with the line Live system (amd64).
Step 6

Fast lane: import a ready-made machine

Action 13 · 5 minutes · only if your professor hands out IT505-Lab.ova
Why this step. An appliance file (ending .ova) contains a complete, finished VM (Virtual Machine). Importing it replaces steps 3 to 5 of this guide and the whole of Guides 2 and 3.

Choose File > Import Appliance, select the file IT505-Lab.ova, keep the proposed settings, among them Generate new MAC (Media Access Control) addresses for all network adapters, which gives the network card of your copy a hardware number of its own, and choose Finish. Start the machine and log in with the account your professor names. Then change its password in a terminal with the command passwd.

AttentionAn imported machine carries the passwords chosen by the person who built it. Change the password of the account at once, and run sudo bash it505_setup.sh once more to choose your own database password (Guide 3, step 1).
✔ Done when: IT505-Lab starts and shows the login screen of Debian.
Help

If something goes wrong

Seven frequent situations, with their cause and remedy
What you seeCause and remedy
VT-x is disabled in the BIOS or AMD-V is disabledHardware virtualization is switched off in the firmware of the host. Intel calls this function VT-x (Virtualization Technology for x86 processors) and AMD (Advanced Micro Devices, a maker of processors) calls it AMD-V (AMD Virtualization); older computers call the firmware the BIOS (Basic Input/Output System). Restart the computer, open the firmware setup, often with the key F2, F10 or Del during start, and enable Intel Virtualization Technology or SVM (Secure Virtual Machine) Mode.
A green turtle icon at the bottom of the VM (Virtual Machine) window (Windows host)The Windows hypervisor Hyper-V is active, and VirtualBox has to run through it, slowly. In Turn Windows features on or off untick Hyper-V, Virtual Machine Platform and Windows Hypervisor Platform, restart, and check again. The Windows Subsystem for Linux, version 2, needs these features; you cannot use both at full speed.
The installer asks for Microsoft Visual C++ RedistributableInstall the x64 package from Microsoft, then start the VirtualBox installer again.
The VM window stays black after StartPower off the VM; in Settings > Display make sure 3D Acceleration is unticked and Video Memory is 128 MB (megabyte).
Kernel driver not installed (rc=-1908) on a Linux or macOS hostThe driver of VirtualBox is not loaded. Linux: install the packages dkms and the kernel headers, then run sudo /sbin/vboxconfig. macOS: allow the Oracle software under System Settings > Privacy & Security, then restart.
The VM starts, but the mouse is caught inside itPress the Host key (right Ctrl; left Command on macOS).
The host becomes very slow while the VM runsThe VM has too much memory for this host. Power it off and reduce Base Memory to 2048 MB under Settings > System.
