The flat-file inspector (Python)

TaskA Python script that inspects the Mercadillo 505 export before loading: it reads the raw bytes, checks for a byte order mark, shows how UTF-8 (Unicode Transformation Format, 8-bit) stores “á” and what the wrong encoding displays, splits every line both naively and with the quote-aware csv module, reports the malformed line, and writes the valid records as JSON Lines and TSV (Tab-Separated Values).

How it relatesIt is the real-life example executed line by line. Each printed result answers one of the inspection questions of Lesson 1; the live table on the right shows every line split into fields, with the naive count, the correct count and the verdict.

How the code works — step by step

  1. Lines 2–7 import the csv and json modules and name the file. Only Python's standard library is used, so nothing has to be installed.
  2. Lines 8–11 open the file in binary mode and read the bytes, so that the encoding can be examined before any decoding.
  3. Lines 12–21 print the size (1,827 bytes), check for the BOM (Byte Order Mark) (none), show “á” as the bytes C3 A1, decode the file as UTF-8 and show the mojibake “AlcalÃ¡” that a Windows-1252 reader would display.
  4. Lines 22–27 split the text into lines, let the csv module read the header and report its 13 fields.
  5. Lines 28–45 visit the 12 data lines. For each one the naive split (cut at every comma) and the csv module (respect quotes) count the fields. Lines 5 and 6 give 14 and 13: the quoted commas of “Ruiz, Marta” and “Olive-oil tortas, 6 units” are handled correctly. Line 11 gives 14 and 14: the line is malformed and its number is collected.
  6. Lines 46–53 read the lines again with a DictReader, keep the 11 valid records (a malformed line carries an extra value under the key None) and show that every value is text: unit_price is the string '7.40'.
  7. Lines 54–61 write one JSON (JavaScript Object Notation) object per line into m505_excerpt.jsonl, with ensure_ascii=False so that accents stay readable, and print the start of the first record: every value now travels with its name.
  8. Lines 62–73 write the same records as m505_excerpt.tsv with a tab delimiter and confirm the two new files.
